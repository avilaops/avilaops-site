# O que é link interno e por que ele importa

Link interno é um link que leva de uma página do seu site para outra página do mesmo site. O menu é link interno; o "veja também" no fim de um texto é link interno; a palavra sublinhada no meio de um parágrafo que leva para a página do serviço é link interno. Ele serve para duas coisas: guiar o leitor e mostrar ao Google como o seu site se organiza.

É o recurso de SEO mais barato que existe. Página sem nenhum link apontando para ela é chamada de órfã, e órfã tem mais dificuldade de ser [indexada](https://avilaops.com/guias/o-que-e-indexacao-pagina-nao-existe-google/).

## O que o link interno faz pelo Google?

Primeiro, descoberta: o robô chega numa página e segue os links dela. Segundo, importância: páginas que recebem muitos links de dentro do próprio site são lidas como centrais.

Terceiro, contexto: o texto do link diz ao Google do que trata a página de destino. Um link escrito "clique aqui" não diz nada. Um link escrito "planos da loja virtual" diz do que se trata. Esse texto se chama texto âncora.

Uma pousada em Olímpia tem 15 páginas, mas o menu só mostra quatro. As outras 11 não são linkadas de lugar nenhum. O Google indexou as quatro do menu. Bastou linkar as outras a partir da página inicial e dos textos para o robô encontrá-las nas semanas seguintes.

## Como uso link interno sem exagerar?

Regra prática: toda página importante deve ser alcançável em até três cliques a partir da página inicial. Toda página nova recebe pelo menos dois links de páginas já existentes. Todo texto explicativo linka para a página de serviço que resolve o problema descrito.

No texto do link, use a palavra que descreve o destino, não "aqui" ou "saiba mais". Não linke a mesma página cinco vezes no mesmo parágrafo; uma vez basta. A [página de categoria](https://avilaops.com/guias/pagina-de-categoria-mais-visitada-menos-cuidada/) é o lugar onde mais se ganha com isso em lojas.

## Perguntas frequentes

**Link interno é a mesma coisa que backlink?**
Não. Backlink é link que vem de outro site para o seu; depende de terceiros e é mais difícil de conseguir. Link interno está sob o seu controle e você pode ajustar hoje.

**Quantos links internos por página?**
Não há número certo. Os que fizerem sentido para o leitor. Um texto de 600 palavras com dois a cinco links relevantes está bem servido.

**Link no menu vale mais que link no texto?**
Os dois contam. O link no texto tem a vantagem do contexto: a frase ao redor explica ao Google do que trata o destino. Por isso menu e texto se complementam.
