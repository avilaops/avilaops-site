# O que é integração entre dois sistemas

Integração entre dois sistemas é quando um deles avisa o outro, sozinho, que algo aconteceu. A loja virtual registra a venda e o controle de estoque baixa o produto. Ninguém digita a venda duas vezes. A integração é o canal por onde a informação passa de um lado para o outro sem pessoa no meio.

O problema que a integração resolve tem nome: retrabalho. Você fecha a venda no site, depois lança no caixa, depois anota no estoque, depois copia o endereço para a etiqueta. Quatro digitações, quatro chances de erro. Em junho, com a loja física vendendo presente e o site vendendo o mesmo presente, o erro vira produto vendido duas vezes.

## O que a integração faz na prática

Cada sistema guarda um pedaço da operação. Sem integração, você é a ponte entre eles. Com integração, o pedido pago no site aparece no estoque como baixa, no WhatsApp como mensagem de confirmação e no financeiro como entrada. Uma vez. Na hora.

Numa floricultura que vende arranjo de Dia dos Namorados no site e no balcão, com integração, a venda do balcão baixa o mesmo estoque que o site vê. Sem integração, o site continua vendendo o arranjo que acabou às 14h, e às 18h você liga para três clientes para cancelar.

## O que a integração não faz

Não conserta cadastro ruim. Se o produto tem um código no site e outro no estoque, a integração não sabe que são a mesma coisa. Antes de ligar dois sistemas, os dois precisam usar o mesmo código para o mesmo produto.

Não é permanente por natureza. Sistemas mudam de versão, senhas expiram, e a integração pode parar em silêncio. Toda integração precisa de um jeito de avisar quando quebra.

E não é obrigatória. Se os dois sistemas trocam informação uma vez por semana e são cinco linhas, copiar à mão é honesto. Integração vale quando a troca é diária e o erro custa venda.

## Perguntas frequentes

**Integração e automação são a mesma coisa?**
São parentes. Automação é a regra que executa uma ação. Integração é o canal que leva a informação de um sistema para o outro. A maioria das automações úteis depende de uma integração por baixo: para mandar o WhatsApp de confirmação, o sistema de mensagens precisa saber que o pagamento caiu.

**Meus sistemas precisam ser da mesma empresa para integrar?**
Não. O que precisa existir é uma porta de entrada em cada um, chamada interface de programação (API). Sistemas fechados sem API integram mal ou não integram.

**Quanto custa integrar dois sistemas?**
Depende do que cada um permite e de quantas informações precisam cruzar. Na Avila Ops, integração é sob consulta, depois do diagnóstico.
