# Pedir cadastro antes de comprar afasta o comprador?

Afasta. Exigir que o cliente crie conta, com senha e confirmação de e-mail, antes de ver o pagamento está entre os motivos mais citados de carrinho abandonado em pesquisas (Baymard Institute, com compradores dos Estados Unidos). A solução não é deixar de coletar dados: é coletar só o que a entrega e a nota fiscal precisam, no próprio checkout, e oferecer a conta depois que o pedido está pago.

Quem compra pela primeira vez ainda não confia o suficiente para "abrir conta"; quer pagar e receber. Quem já comprou aceita a conta porque viu que a loja entrega. Primeiro a venda, depois o cadastro.

## O que a loja precisa saber para vender?

Seis dados, todos com motivo que dá para explicar ao lado do campo:

| Dado | Para quê |
|---|---|
| Nome completo | Etiqueta de envio e nota fiscal |
| CPF | Nota fiscal eletrônica |
| E-mail | Confirmação do pedido e rastreio |
| Telefone | Aviso de entrega e contato se houver problema |
| Endereço com CEP | Entrega e cálculo do frete |
| Forma de pagamento | Fechar o pedido |

O que não precisa: senha, data de nascimento, gênero, "como conheceu a loja", confirmação de e-mail antes de pagar. Cada um desses pode ser pedido depois, com um motivo, ou nunca.

A conta de cliente é útil para quem volta: guarda endereço, mostra pedidos, facilita a troca. Ofereça na tela de confirmação, com um botão "criar senha para acompanhar o pedido". Quem quiser cria em um clique, porque os dados já estão lá.

## Como funciona a compra sem conta?

A compra como visitante usa os mesmos seis dados e cria o pedido normalmente. A diferença é que não há senha. O cliente acompanha pelo link enviado por e-mail ou WhatsApp e, se voltar, digita os dados de novo ou cria a conta naquela hora.

A maioria das plataformas tem a opção pronta, com o nome "compra como visitante" ou "checkout sem cadastro". Confira se está ligada e teste do celular, como cliente novo, contando os campos. Se aparecer campo que não está na tabela acima, algo sobra. O guia [o que é a tela de fechamento do pedido e por que ela decide a venda](https://avilaops.com/guias/o-que-e-checkout-e-por-que-decide-a-venda/) mostra o restante do que o checkout precisa ter.

Há uma exceção: lojas que vendem só para empresa, com preço por CNPJ e faturamento, ou que precisam aprovar o cliente antes (atacado, produto controlado). Nesses casos o cadastro é parte do negócio e o cliente já espera. Para venda a consumidor, não.

## O que a LGPD exige nesse cadastro?

A Lei Geral de Proteção de Dados vale para qualquer empresa que coleta dado pessoal, inclusive a loja pequena. No checkout, quatro regras práticas:

1. Peça só o necessário para a finalidade (vender e entregar). Pedir data de nascimento "para o aniversário" sem o cliente concordar é coleta além da finalidade.
2. Diga para que serve. Uma linha ao lado do campo ("CPF para a nota fiscal") resolve.
3. Tenha uma política de privacidade com link no checkout, dizendo o que você guarda, por quanto tempo e como o cliente pede a exclusão.
4. Não use o telefone para promoção sem consentimento. O número dado para a entrega não autoriza mensagem de oferta: sem consentimento separado, ela fica difícil de justificar na LGPD e contraria a política do WhatsApp Business. Uma caixa de marcação, desmarcada por padrão, "quero receber novidades por WhatsApp", resolve.

## Como oferecer a conta sem afastar?

Três momentos que funcionam, todos depois do pagamento:

- Na tela de confirmação: "Crie uma senha para acompanhar este e os próximos pedidos". Um campo, um botão.
- No e-mail de envio: link para ver o rastreio, que leva à criação de conta opcional.
- Na segunda compra: o checkout reconhece o e-mail e pergunta se quer usar o endereço salvo.

A conta vira benefício, não pedágio. E o cliente que criou senha depois de receber o produto é o que vai usar. Os outros motivos de abandono, e a ordem para corrigi-los, estão em [carrinho abandonado: os três motivos mais comuns](https://avilaops.com/guias/carrinho-abandonado-tres-motivos/).

## Perguntas frequentes

**É obrigatório pedir CPF na loja virtual?**
Para emitir a nota fiscal ao consumidor, o CPF é o dado que identifica o comprador. Peça no checkout e diga que é para a nota. Não é obrigatório para navegar nem para calcular frete.

**Compra sem cadastro é segura para a loja?**
É. O pedido tem os mesmos dados de entrega e pagamento; só não tem senha. A segurança do pagamento é do intermediário, não do cadastro. O que muda é que o cliente não tem histórico salvo.

**Posso pedir o telefone e usar para mandar promoção?**
Só com consentimento explícito e separado, como uma caixa desmarcada que o cliente marca. O telefone dado para a entrega serve para a entrega. O caminho seguro na LGPD é o consentimento separado; sem ele, a mensagem de oferta fica difícil de justificar e contraria a política do WhatsApp Business.
