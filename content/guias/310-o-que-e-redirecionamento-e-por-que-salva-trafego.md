# O que é redirecionamento e por que ele salva tráfego

Redirecionamento é uma instrução no site que leva automaticamente quem acessa um endereço antigo para o endereço novo. A pessoa clica no link de sempre e chega na página certa, sem ver erro. O Google também segue esse caminho e transfere para a página nova a reputação que a antiga tinha.

Ele é necessário em qualquer mudança: trocar de plataforma, renomear uma página ou mudar de domínio. Sem redirecionamento, todo link antigo, no Google, no Instagram e no WhatsApp de cliente, vira uma página de erro.

## Por que uma página de erro custa tanto?

Porque o link antigo está espalhado em lugares que você não controla: no resultado do Google, num post antigo, numa mensagem encaminhada, num cartão impresso. Cada acesso a um link quebrado é uma visita perdida e um sinal ao Google de que a página sumiu.

Uma clínica trocou de site e a página "clinica.com.br/tratamentos" virou "clinica.com.br/servicos". Sem redirecionamento, o Google continuou mandando gente para o endereço antigo, que dava erro. Em poucas semanas a página nova não tinha herdado nada, e a antiga tinha saído dos resultados. Um redirecionamento de uma linha teria evitado.

## Qual é a diferença entre redirecionamento 301 e 302?

O 301 diz "mudou para sempre". O Google entende que deve substituir o endereço antigo pelo novo nos resultados e passar a reputação.

O 302 diz "mudou por enquanto". O Google mantém o endereço antigo nos resultados, esperando que ele volte. Usar 302 onde deveria ser 301 é erro comum de migração às pressas: o site novo entra no ar, mas o Google segue apontando para o velho.

A regra: toda página que deixou de existir precisa de um 301 para a página mais parecida do site novo. Não para a página inicial; mandar tudo para a home é quase o mesmo que não redirecionar. ## Perguntas frequentes

**Como saber se meu site tem links quebrados?**
O Search Console do Google, gratuito, lista as páginas que retornaram erro. Se ele não está configurado, o guia sobre aparecer no Google mostra como: https://avilaops.com/guias/como-faco-para-minha-empresa-aparecer-no-google/.

**Redirecionamento faz o site ficar lento?**
Um redirecionamento por página não afeta nada perceptível. O problema é encadear vários: A manda para B, que manda para C. Aponte sempre direto para o destino final.

**Preciso de redirecionamento se só mudei de domínio?**
Precisa, e é o caso mais importante. Cada página do domínio antigo deve apontar para a mesma página no domínio novo. E o domínio antigo precisa continuar pago enquanto houver links apontando para ele.
